Open UML

An offline PlantUML editor that actually stays out of your way.

Open UML renders PlantUML diagrams live as you type, with a bundled Java runtime and rendering engine. No accounts. No upload. No Java install dance. Works on Windows and macOS.

Download for Windows / macOS View on GitHub

What you get

Truly offline

The JRE and the PlantUML engine are bundled. Open it once, no network required forever.

Live preview

Diagrams render as you type, with a 300 ms debounce. Multi-diagram files show tabs.

Professional editor

Monaco with PlantUML syntax highlighting, autocomplete snippets, and dark/light themes.

Export anywhere

PNG, SVG, PDF. Or copy the rendered diagram straight to your clipboard.

No telemetry

Zero analytics. The only network call is a one-shot update check against GitHub.

Free, MIT licensed

Built for students, engineers, and technical writers. Use it, fork it, ship it.
