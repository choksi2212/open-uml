# Open UML logo family

Vector masters live in `svg/light` and `svg/dark`; high-resolution raster exports live in the matching `png` folders. The wordmark outlines are derived from IBM Plex Sans SemiBold and the source font is included in `fonts/`.

Design tokens: light `#0f766e` / `#1a1a1a` / `#ffffff`; dark `#22d3ee` / `#f0fdfa` / `#0a1218`.

No gradients, filters, shadows, or external assets are used in the SVG masters.
